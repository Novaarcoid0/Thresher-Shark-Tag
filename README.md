# Thresher-Shark-Tag
This is a shark tag which will monitor the behaviour of the shark by using the heart rate and comparing it with the location (gps). It will also use a hydroelectric generator to get an infinite energy source. This tag will use a microphone to help scientists identify sounds underwater near the shark. This repository will include the CAD and the source code for the tag. If you have any questions, please email yrajpurkar11@gmail.com .
